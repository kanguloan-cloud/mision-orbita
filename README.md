## Descripción del proyecto

Este proyecto contiene cuatro programas desarrollados en Python para representar diferentes etapas de la preparación de una misión espacial.

## Estructura del repositorio

- avance1/mision_orbita.py: cálculo de recursos necesarios.
- avance1/ejercicio2_combustible.py: verificación del combustible.
- avance1/ejercicio3_soporte_tripulacion.py: verificación de oxígeno y provisiones.
- avance1/ejercicio4_lanzamiento.py: autorización del lanzamiento.
- Documentación/avance1.pdf: documentación del primer avance.

## Requisitos

- Python 3 instalado.
- Un editor de código, como Visual Studio Code.

## Cómo ejecutar los programas

Desde la carpeta principal del repositorio, ejecutar:

python avance1/mision_orbita.py

python avance1/ejercicio2_combustible.py

python avance1/ejercicio3_soporte_tripulacion.py

python avance1/ejercicio4_lanzamiento.py
